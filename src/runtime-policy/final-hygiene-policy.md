# Final project hygiene policy

## Checkpoint
Kör löpande efter relevanta steg.

## Final
Kör inför release och behandla resultatet som release gate.

## Auto-clean
Endast kända temporära/genererade artefakter får raderas automatiskt.

## Osäkra filer
Historiska namn eller duplicering ska flaggas för bedömning, inte raderas blint.

## Resultat
- pass
- warning
- blocked
