# Runtime parity policy

## Regel

Jämför Chat ZIP och Custom GPT per funktionell capability.

## Primär referens

Chat ZIP representerar full avsedd funktionalitet för ZIP-first projekt.

## Nivåer

- equivalent
- reduced
- missing
- not_applicable

## Kritikalitet

- critical
- important
- optional

## Release

Saknad critical capability kan göra Custom GPT `not_viable`.

## Rapport

Paritetsrapport ska generera underlag till `COMPATIBILITY.md` och releasebedömningen.
