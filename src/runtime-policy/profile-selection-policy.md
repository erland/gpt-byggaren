# Reference profile selection policy

## Profiler
- simple
- standard
- zip_first_advanced
- workflow_research_heavy

## Regel
Välj närmaste profil från användningsfallet och dokumentera avvikelser.

## Härled från
- arbetsflödets komplexitet
- Knowledge-volym/struktur
- scripts
- schemas
- fil- och ZIP-hantering
- käll/evidenskrav
- Custom GPT-begränsningar

## Fråga inte
Be normalt inte användaren välja profil.
