# Direct build policy

## Regel

GitHub är valfritt.

GPT Byggaren ska kunna bygga och leverera färdiga GPT-artefakter direkt.

## Före leverans

Kör:

1. project hygiene,
2. build,
3. distribution validation,
4. paritybedömning när flera runtimes finns,
5. checksummor.

## Version

Utan GitHub Release används en tydligt markerad utvecklings- eller RC-version.

## Leverans

Ge användaren länkar till alla skapade artefakter.
