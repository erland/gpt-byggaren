# Vanliga frågor – GPT Byggaren

## Måste jag förstå projektfilerna?
Nej. De finns främst för att GPT Byggaren ska kunna arbeta konsekvent och återuppta projektet senare.

## Vilken ZIP ska jag spara?
Spara alltid senaste **projekt-ZIP:en** om du vill kunna fortsätta utvecklingen.

## Är Chat ZIP samma sak som projekt-ZIP?
Nej. Chat ZIP är runtime. Projekt-ZIP är utvecklingsprojektet.

## Måste jag använda Custom GPT?
Nej. För avancerade projekt kan Chat ZIP vara den viktigaste distributionen.

## Måste jag använda GitHub?
Nej. GitHub är valfritt.

## Kan jag fortsätta i en ny chat?
Ja. Bifoga senaste projekt-ZIP:en.

## Behöver jag bestämma om schemas och tester?
Normalt nej. GPT Byggaren ska härleda det från användningsfallet.

## Vad händer om planen behöver ändras?
GPT Byggaren får anpassa planen och dokumenterar förändringen i projektstatus.

## Vad betyder release-ready?
Att blockerande kvalitetskontroller är godkända och distributionerna kan byggas på ett kontrollerat sätt.
